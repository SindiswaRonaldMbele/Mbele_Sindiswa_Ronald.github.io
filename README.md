# Sindiswa Ronald Mbele Multi-Page Portfolio

This is not a one-page website. It is a routed Flutter Web portfolio with separate screens.

Pages: `/`, `/data`, `/software`, `/it`, `/mathematics`, `/projects`, `/education`, `/skills`, `/experience`, `/certifications`, `/achievements`, `/contact`, `/admin`.

## Run

```bash
flutter pub get
flutter run -d chrome
```

## Firebase

```bash
flutterfire configure --project=profile-1e99b --platforms=web
firebase deploy --only firestore:rules
```

Only `sindiswaronald@gmail.com` can edit. Public users can read.

No PDF. No Research page. No Business page.
